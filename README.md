# medSave

MedSave is a frontend-only medicine inventory and expiry tracking dashboard built with React, Vite, JavaScript, and Lucide icons.

## Run locally

1. Install Node.js (version 20.19+ or 22.12+).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address Vite prints (usually `http://localhost:5173`).

Use `npm run build` to create a production build.

Medicine and settings changes are saved in this browser's local storage. The sample data is for demonstration only. This phase does not send notifications or connect to a server.
